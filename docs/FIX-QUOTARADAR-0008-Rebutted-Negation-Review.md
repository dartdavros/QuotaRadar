# Перепроверка отказов для подтверждённого автора Codex

Исправление согласовано владельцем 22 октября 2026 после пропуска поста `@thsottiaux`
`2113162277688070445`:

> Day 17/ Bet you thought we forgot, but no, it’s reset day today.

Пост получен через 3 минуты после публикации. LLM вернула `is_relevant=false`.
Правило серии FIX-0007 не сработало: нет отдельной строки `Day N/ Reset`.
Перепроверка FIX-0006 не запустилась: фильтр отрицаний принял `no, it’s reset`
за отказ от сброса. Объявление опубликовано вручную по указанию владельца
(анализ 1744, доставка 1479, message ID 106).

## Поведение

- Отрицание больше не распространяется через `,` `;` `:` `—` `?`. Фраза
  «but no, it’s reset» не считается отрицанием; «No reset today» и
  «We will not reset» по-прежнему считаются.
- Отрицания распознаются и с типографским апострофом `’`: `won’t`, `don’t`,
  `didn’t`, `can’t`, а также `cannot`.
- Для подтверждённого автора (X author ID `1953337039510003712`, проверка FIX-0007)
  перепроверку отменяют только технические темы: Git, API, лимиты запросов,
  инфраструктура, пароли, настройки, отдельный аккаунт. Вопросы и отрицания
  оценивает сама повторная оценка; она по-прежнему должна подтвердить `quota_reset`
  и пройти проверку провайдера, продукта и текста.
- Для других доверенных источников критерии перепроверки не меняются.
- Правило серии `Day N/ Reset` по-прежнему исключает вопросы и отрицания и не
  распространяется на свободный текст.

## Влияние

Сравнение старого и нового условия только на чтение по 1182 постам `@thsottiaux`
в production (с 16 июля 2026): решение о перепроверке изменилось у 16 постов.

- 8 из них LLM распознала как сброс с первого ответа; перепроверка им не нужна.
- Посты 2109873287853707513 и 2113162277688070445 получили бы перепроверку
  ошибочного отказа.
- 7 постов — вопросы и шутки о reset, которые LLM отклонила. Для таких постов
  добавится один запрос к LLM. Если повторная оценка тоже откажет, анализ
  получает `failed` с причиной и событием мониторинга, как задано в FIX-0006.
  Ожидаемая частота — около одного поста в две недели.

## Границы

Промпты, миграции, UI, доставка и учётные данные не меняются. Ранее завершённые
анализы автоматически не пересматриваются. Эвристика выбирает отказы для
перепроверки и не публикует посты сама.

## Проверка

Изменены `apps/analysis/reset_signals.py` и тесты
`apps/analysis/tests/test_reset_signals.py`, `apps/analysis/tests/test_reassessment_tasks.py`.
Тесты используют реальные тексты постов 2113162277688070445, 2109873287853707513,
2106233145163141249 и 2105672058269212820. Ответы LLM изолированы через `unittest.mock`.

Целевые тесты `test_reset_signals`, `test_series_reset`, `test_reassessment_tasks`
и `test_series_reset_tasks` прошли в штатном Docker test-сервисе с PostgreSQL и Redis:
28 тестов, OK.

Production-выкладка не выполнялась и требует отдельного согласования владельца.

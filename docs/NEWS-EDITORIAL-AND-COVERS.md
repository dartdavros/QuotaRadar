# Редакционный текст и обложки новостей

Утверждено владельцем 30 сентября 2026: обложка №3, затем поручение реализовать новостной контур.

## Текст

Промпт редактора `news_writing` v5 описывает спокойную фактическую редактуру.
Объём определяется материалом. Убраны пример с обращением к «вайбкодеру», обязательный вывод
о пользе и требование заполнять 400–750 символов в JSON-схеме. Заголовок сообщает изменение,
первый абзац раскрывает его; краткое смысловое пересечение допустимо.

Проверяющий `news_verification` v3 возвращает два независимых решения:
`supported` о фактах и `editorial_quality` о стиле. Обе проверки обязательны.
Причина отказа возвращается редактору при следующей штатной попытке подготовки.
Индивидуально выбранные промпты с другим code или version сохраняются; их прежний контракт
проверки фактов остаётся совместимым. Обращение к «вайбкодерам» дополнительно отсеивается кодом.
Переключение с штатных writing v4 / verification v2 выполняет миграция 0009.

## Визуальный baseline

![Утверждённый вариант №3](assets/news-cover-style-3.jpg)

Тёплый светлый фон, матовые материалы, мягкий направленный свет, графит и сдержанная терракота.
Одна понятная физическая метафора конкретного события, небольшое число объектов, свободное пространство.
Сюжет меняется по подтверждённым фактам. Ноутбук и облако из образца не являются общим шаблоном
для всех новостей. Запрещены выдуманные интерфейсы, числа, графики, возможности, рекламные
лозунги, роботы, лица, мозги, неон, голограммы и случайный код.

Образец без логотипа поставляется с кодом как `apps/news/assets/covers/style-3.jpg` и передаётся
генератору в качестве референса стиля. Промпт находится в `cover_art.py`, style version = 1.
Формат: 16:9, 1K, Nano Banana 2 `google/gemini-3.1-flash-image`, OpenRouter Image API.
Используются существующий ключ LLM и общая HTTP-фабрика: настроенный прокси либо прямое подключение, если прокси отключён. Другой провайдер не подставляется.

Логотип выбирается по главному продукту события, а не случайному упоминанию в тексте.
Для Codex/ChatGPT/моделей OpenAI используется официальный wordmark OpenAI; для Claude и
Claude Code — соответствующие логотипы, для Cursor — официальный горизонтальный lockup,
для Google/Gemini — Google. Происхождение, дата получения, архивный путь и SHA-256 каждого
файла указаны в `assets/covers/manifest.json`. Программное наложение сохраняет пропорции и цвета.
Модель логотип не рисует. Неизвестный продукт без утверждённого ассета блокирует подготовку,
пока владелец не предоставит решение; логотип компании источника автоматически не заимствуется.

## Подготовка, стоимость и доставка

Оригинальные фото, видео и анимации имеют приоритет и проходят прежние проверки.
Обложка генерируется только после проверки текста и только при полном отсутствии вложений
у выбранных первоисточников. Неполное или повреждённое оригинальное медиа не заменяется генерацией.

На публикацию допускается один платный запрос изображения. Резервируется `cover_requested_at`
под блокировкой строки публикации до HTTP-запроса. При потере ответа или воркера повторный
платный запрос не выполняется автоматически. Новость получает blocked с причиной; текст без
обложки в этом случае не отправляется. Восстановление требует отдельного решения владельца.
Неопубликованные результаты после отключения отправки сохраняются, но не доставляются.

Готовое JPEG, SHA-256, размер, модель, фактический usage/cost, промпт и хеши ассетов хранятся
в MediaAsset. Бинарные данные сохраняются в PostgreSQL, чтобы разные воркеры и пересозданные
контейнеры использовали то же изображение. Не требуются новые mounts, публичный URL или
изменение постоянных путей. Размер обложки ограничен проверкой изображения и нормализацией JPEG.
Это увеличивает размер БД и её резервных копий; автоматическое удаление оригинала обложки не введено.

Доставка использует `sendPhoto` и multipart-upload из сохранённых байтов, затем file_id того же бота.
Перед загрузкой проверяется SHA-256. Смена бота использует сохранённый JPEG.
Содержание обложки включено в идентичность публикации через SHA-256; хеши старых оригинальных
медиа сохраняются совместимыми. Поведение uncertain и ручное разрешение доставки не изменяются.

## Проверка и выкладка

Проверяются только редактура, новый путь обложек и непосредственно затронутые сценарии
подготовки/доставки. Изолированные unit-тесты не отправляют запросы в X, OpenRouter или Telegram.
Их тестовые записи не являются запуском новостного потока и не используются для демонстрации UI.
Живая визуальная проверка использует реальные архивные новости и OpenRouter, без отправки в канал.

Первичная реализация и проверка выполнялись локально. Перед выкладкой требуется точный план:
резервная копия БД, сборка образа с Pillow и ассетами, остановка процессов новостной подготовки
и отправки, применение news 0009/0010, запуск, проверка настроек и очередей, порядок отката.
Не делать push в main без поручения: штатный CI автоматически запускает production deployment.

## Результат проверки 30 сентября 2026

Штатная Docker-сборка успешна; Django check и makemigrations --check --dry-run без ошибок.
55 целевых тестов прошли в PostgreSQL/Redis: редакционная политика, API-контракт изображений,
официальные ассеты, конкурентный резерв платного запроса, сохранение и доставка обложки,
подготовка, оригинальные медиа и затронутая историческая подготовка. Обнаруженная в первом
прогоне ошибка n_frames для JPEG исправлена; повторены только упавшие сценарии.
В браузере проверены существующие настройки новостей и пустой журнал медиа.
Локальный новостной поток остаётся выключенным; живая отправка в Telegram не проверялась.

Два реальных архивных материала (Claude Code #71, Cursor #76) проверены через существующий
LLM-адаптер с новыми промптами: оба получили supported=true и editorial_quality=true.
База production читалась в транзакции READ ONLY, материалы и настройки не менялись.
Один реальный запрос новым генератором с референсом стиля №3 успешно вернул изображение
для Cursor: фактическая стоимость $0.0679595. JPEG с официальным логотипом собран тем же
кодом compose из штатного локального образа и визуально проверен. Артефакты сохранены
локально вне репозитория; в канал не отправлялись. Production-код не обновлялся.

## Запрошенная владельцем серверная выкладка

Перед релизом полный штатный набор из 346 тестов прошёл. На сервере проверены все 34 файла
пакета изменения: существующие совпадают с локальным исходным HEAD, новые отсутствуют.
На момент проверки нет preparing/ready/sending/uncertain новостей; активны writing v4 / verifier v2.

Порядок выкладки: сохранить старый образ отдельным rollback-тегом и изменяемый код в защищённом
каталоге `/opt/quotaradar/backups/news-covers-20260930-<commit>`, загрузить проверенный SHA-256
пакет и обновить только перечисленные файлы внутри существующего `/opt/quotaradar`.
Собрать новый образ при работающем старом приложении, затем штатно остановить web, bot,
worker, news-worker, news-urgent и beat с ожиданием завершения задач до 300 секунд.
PostgreSQL и Redis продолжают работать. Выполнить pg_dump в custom format и проверить каталог
дампа через pg_restore --list; применить миграции и collectstatic через штатный init,
проверить промпты, ассеты и контракты, затем запустить приложение и проверить здоровье сервисов.

Пути хранения, Compose, volumes, .env и master.key не меняются; старые публикации не переписываются.
Push в main и автоматическое переключение deployment-каталогов не выполняются.
При сбое вернуть исходные файлы и закреплённый старый образ. После применения миграций
бинарные данные обложек и добавленные поля не удалять: восстановить прежний выбор промптов
и оставить новостные процессы остановленными до разбора; данные БД автоматически не откатывать.

Выкладка 30 сентября 2026 завершена: runtime-коммит `dd56e41`, 35 файлов сверены по SHA-256.
Шесть процессов приложения работают на одном новом образе; PostgreSQL/Redis healthy,
web healthy и страница входа возвращает HTTP 200. Три Celery-воркера отвечают pong.
Включены сбор, анализ, публикация и прежний канал; writing v5 / verifier v3 выбраны миграцией.
Шесть официальных логотипов и композиция проверены в production; прежние frozen-хеши не изменились.
Telegram getMe/getChatMember подтвердили работающий токен и права администратора канала;
искусственная новость или повторная отправка архивного материала не выполнялись.

Дамп PostgreSQL: 46 462 544 байта, pg_restore --list проверен; старый код, исходный образ,
метаданные и SHA-256 сохранены в `/opt/quotaradar/backups/news-covers-20260930-8cf176a`.
Каталог backup исключён из Docker build context отдельным правилом .dockerignore;
в итоговом образе `/app/backups` отсутствует. Старый образ имеет тег
`quotaradar:rollback-news-covers-8cf176a`. Код и БД для отката автоматически не удаляются.
